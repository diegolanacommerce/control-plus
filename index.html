⚙️ Configurar Sincronização
Para salvar seus dados na nuvem e acessar de qualquer dispositivo, configure um projeto Firebase gratuito.
1. Acesse console.firebase.google.com
2. Crie um projeto (gratuito, plano Spark)
3. Vá em "Autenticação" → "Sign-in method" → ative Email/Senha
4. Vá em "Firestore Database" → crie banco (modo produção)
5. Em "Regras" do Firestore, cole:
rules_version='2'; service cloud.firestore { match /databases/{db}/documents { match /users/{uid}/{document=**} { allow read,write: if request.auth.uid==uid; } match /licenses/{key} { allow read: if request.auth != null; allow write: if request.auth.token.email == 'diegolanacommerce@gmail.com'; } } } 6. Em "Configurações do projeto" → "Seus apps" → adicione app web → copie as credenciais abaixo
